# Michelle Relayze — Web Oficial ✦

Sitio oficial de **Michelle Relayze**, primera **Miss T Supranational 2024**.
Construido con HTML5 + CSS3 y JavaScript moderno (arquitectura OOP), con una capa GSAP para animación editorial.

## Dirección editorial
La experiencia busca mostrar a Michelle más allá de los títulos: persona, sensibilidad, comunidad, recorrido y trabajo.
Las notas editoriales no se presentan como citas textuales de Michelle.

## Secciones
- Biografía y línea de tiempo (Lima → Uruguay → Florencia → Barcelona → São Paulo)
- Corona: Miss T Supranational 2024, Miss Trans Star Spain 2019, Miss Congeniality
- Cine & TV: Heels Over Wheels (2022), La Casa de las Reinas (2023), Nocturnas (2023)
- Carrera: Axel Hotels, Miau Events (CEO), Proescenic Talent Agency
- Activismo: Stop Sida, Pride Barcelona 2025 (Master of Ceremony)
- Galería con lightbox y notas editoriales rotatorias
- Archivo final con acceso al código fuente

## Deploy
El proyecto está preparado como sitio estático. El deployment activo puede gestionarse desde Vercel conectado al repositorio `main`.
